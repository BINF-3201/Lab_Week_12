## Step 3 - Start the genome annotation

The genome annotation generated by plasmidsaurus is ok, but we want to use a better method. We will use Funannotate - this is what we used last week. We will also add a **functional annotation** step that will tell us more about what the function of the genes in the genome are. 

### Step 3a - make a new folder

Make a new folder to conduct your analysis and then move into that folder

```
mkdir wildyeast
cd wildyeast
```

### Step 3b - copy over genome and slurm file

Your genome is currently on the cluster and ready to copy over. It is fasta format, which is what we used last week as well

```
cp /projects/class/binf3201_001/assemblies/ASSEMBLYNAME_reference.fasta .
cp /projects/class/binf3201_001/assemblies/funannotate.slurm .
```

### Step 3c - Prepare our sequences for analysis

We will prepare our assembly following these instructions: https://funannotate.readthedocs.io/en/latest/prepare.html#prepare

Don't forget to **USE YOUR GENOME NAME**

#### Load funannotate

```
module load funannotate
```


#### Clean the genome

```
funannotate clean --input ASSEMBLYNAME_reference.fasta --out ASSEMBLYNAME_reference.clean.fna
```

#### Sort and rename FASTA headers

We will also remove any contigs less than 500bp

```
funannotate sort --minlen 500 --input ASSEMBLYNAME_reference.clean.fna --out ASSEMBLYNAME_reference.sorted.fna
```

#### Repeatmask our genome

```
funannotate mask --input ASSEMBLYNAME_reference.sorted.fna --out ASSEMBLYNAME_reference.masked.fna
```
